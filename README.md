## TERAIN GENERATION SIMULATOR

WEBSITE LINK: https://a4-creativecoding.onrender.com/

An interactive 3D terrain generator built with Three.js. The surface is built from layered simplex noise displacing a subdivided plane in real time. A translucent water plane sits at an adjustable sea level, so raising or lowering it floods or reveals more of the landscape.

The goal of this project was to learn how to use 3D elements in my websites. I have never done something like this before, and I had a fun time learning how to use Three.js. 

Challenges:
- Using noise: I had to implement 2 npm packages, simplex-noise and alea
- Keeping the terrain's edges from looking like an abrupt square cutoff
